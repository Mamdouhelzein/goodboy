# Resume Writer

Write or improve a resume/CV and cover letter: structure, strong bullet points, tailoring to a job description.

## Bullets

Action verb, what you did, measurable result.

## Tailoring

Mirror the job posting's key skills honestly.

## Format

One page for students, clear sections: education, experience, projects, skills.
