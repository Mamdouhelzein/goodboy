# Regex Builder

Write, explain and test regular expressions for matching or extracting text patterns such as emails, IPs, dates or log fields.

## Approach

Start from real examples, anchor the pattern, prefer explicit character classes.

## Testing

Test with positive and negative examples in Python re or grep -E.

## Common patterns

IPv4, email, ISO dates, UUIDs.
