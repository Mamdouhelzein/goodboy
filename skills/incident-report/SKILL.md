# Incident Report

Write a security incident response report or postmortem: summary, timeline, impact, root cause, containment and lessons learned.

## Structure

Executive summary, timeline, scope and impact, root cause, actions taken, follow-ups.

## Timeline

Use UTC timestamps and cite the evidence for each event.

## Tone

Blameless, factual, specific about what is still unknown.
